Hard rules
- **No Bayesian optimisation anywhere** (no skopt). Use multi-start around the nominal guess instead.
- Every notebook writes its figures to `figs/` (PNG, 300 dpi, and also PDF) and a `results/<nb>.json` containing **every number** that could appear in the paper (fitted parameters, losses, MAE/σ, bounds, iteration counts, function evaluations, timings, thresholds). The writer and reviewers only use numbers from these JSONs.
- Figures are for a single-column Optica page (text width ≈ 13.3 cm). Font size ≥ 7 pt at final size, consistent style across notebooks: put a shared `code/paperstyle.py` (rcParams, a colour-blind-safe palette, helper for panel labels (a), (b), …). Keep each figure compact — the paper has 8 pages for ~7 figures.
- Double precision for all fits.
- Do not change the physics conventions (ñ = n − iκ, κ > 0 = loss, same TMM as `Simulate.py`).
- Write a `notebooks/README.md` listing notebook → figures → JSON.
