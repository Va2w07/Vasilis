# paper_v3 — 8-page revision of the THz multilayer extraction paper (2026-11-24)

Produced by a five-role agent pipeline (writer, coder, domain reviewer, outside reviewer, director = Claude Fable; sub-agents on Claude Opus from loop 1) over three review loops. Every decision and every disagreement between agents, with the director's ruling, is in `DECISIONS_LOG.md`.

## What is here
- `main.tex`, `refs.bib`, `main.pdf` — the manuscript (Optica universal template, 8 pages incl. references; class/style files included so it compiles standalone with pdfLaTeX + BibTeX, e.g. on Overleaf). Red `\todo{}` items are for the authors (author list, sample details, mechanical thicknesses, funding, data link).
- `figs/` — the six paper figures (PNG 300 dpi + PDF), all regenerated by the notebooks; `figs_old/` keeps the figures of the previous manuscript for reference.
- `notebooks/` — `nb1`…`nb6` regenerate every figure and every number (see `notebooks/README.md`); `results/nbX.json` holds all numbers used in the paper, `results/*_cache.npz` the heavy fits (set `RUN_FULL = True` in a notebook to recompute).
- `code/` — the Python modules the notebooks use (TMM forward model, L-BFGS extractor, six-knot dispersive model, landscape/PCA tools, paper figure style).
- `data/` — the measured traces used (quartz/Si 15 min, quartz–air–Si run 3, polyimide/Si, reference pulses).
- `reviews/` — all agent reports: coder reports, writer reports, the three domain and three outside reviews, the reference verification, and the compiled PDF of each loop.
- `briefs/` — the briefs given to the agents and `compile.sh`.

## Main changes versus the previous manuscript (details in DECISIONS_LOG.md)
1. 20 → 8 pages; Bayesian seeding removed (one sentence that it was tried and was inefficient); polynomial dispersion model removed; old Figs 6 and 7 removed; Section 7 is now L-BFGS vs Adam with the L-BFGS trajectory figure; Section 8 is the quartz–air–Si run-3 six-knot fit.
2. Thin-film limits with the measured reference pulse, plus the polyimide-on-Si experiment (bracketed by two references that measure a 40 fs time-zero drift; without a nuisance parameter n_Si is physical and d_PI = 26.4 µm vs profilometer 24.7 µm, a few-percent systematic set by reference reproducibility). Updated 2026-11-27 with the 25 Nov reference–sample–reference bracket (nb2 Part C, results/nb2.json → pi_2511).
3. Three claims of the old manuscript withdrawn after checks: (a) "κ is 280×/890× less visible than n" was the n/κ unit ratio; (b) the soft direction is a transfer of physical thickness between layers (n₁d₁, n₂d₂ and d₁+d₂ all fixed by the pulse timings), not an "n–d anti-phase" direction; (c) a dispersive model does *not* remove the negative κ_Si — the attenuation split between layers is model-limited and only a κ ≥ 0 (softplus) constraint makes it physical.
4. Cramér–Rao argument rewritten step by step with the non-white pre-pulse noise and the 41σ residual accounted for.
5. All 39 references verified (9 corrected, Greenall2017 dropped as unverifiable; see `reviews/refs_verification.md`); 17 remain cited.
